# 📝 HTML/CSS 실습 - k8_html

## 📌 소개

이 저장소는 HTML과 CSS의 기초를 학습하고, 다양한 웹페이지 구조와 레이아웃을 실습하기 위해 만들어졌습니다.
K-Digital Training 과정 중 웹 퍼블리싱 능력을 향상시키기 위한 실습 위주 프로젝트로,
정적 웹사이트 구조 이해와 기본 스타일링 연습을 중점적으로 진행하였습니다.

시맨틱 태그 사용, Flex/Grid 레이아웃 구성, 반응형 기초 스타일링까지 다양한 내용이 포함되어 있습니다.

---

## 🛠 사용 기술

- HTML5
  - 시맨틱 마크업 (`<header>`, `<main>`, `<footer>`, `<section>` 등)
  - 리스트, 테이블, 폼 태그 등 다양한 HTML 요소 사용
- CSS3
  - 선택자 및 박스 모델
  - Flexbox / Grid 레이아웃
  - 색상, 폰트, 버튼 등 스타일 요소 구성
  - 반응형 웹을 위한 미디어쿼리 기초

---

## ✨ 학습 포인트

- HTML 문서의 구조와 기본 태그에 대한 이해
- 시맨틱 태그를 활용한 접근성 있고 구조적인 마크업 연습
- CSS Flexbox와 Grid 시스템을 활용한 레이아웃 구현
- 웹 페이지 퍼블리싱에 필요한 UI 요소 스타일링
- 정적 웹사이트의 폴더 구성과 웹페이지 흐름 파악
- 직접 디자인과 마크업을 해보며 퍼블리싱 실무 감각 향상
